Machine model
One RV32IM core, little endian, 32 integer registers, 16 MiB RAM. Instructions run sequentially through fetch, decode, execute, memory, and writeback. Read ports latch at decode; the write port commits at writeback.
The ALU uses a 32-bit ripple-carry adder/subtractor, bitwise logic, a five-stage barrel shifter, and a comparator. The simulator uses these outputs to execute instructions. Carry reveal is a display control and does not advance CPU cycles. Multiply/divide uses a 64-bit shift-and-add multiplier and a 33-bit restoring divider. Both take 34 execute cycles: prepare, 32 bit iterations, then sign correction and result selection. AND gates form partial products; a subtractor and AND/OR multiplexer update the remainder. All arithmetic comes from the displayed full-adder gates. Gate propagation delays are not modeled.
Caches use 64-byte lines, direct mapping and write-through stores. Lookup latencies accumulate: L1 1, L2 6, L3 18, RAM 60 cycles. Each cache lookup completes before the next level starts. A RAM read returns a 64-byte line; refills then take one cycle per upper cache, from L3 toward L1. A cold read takes 88 cycles; L2 and L3 hits take 8 and 27 cycles. Stores add a 60-cycle write-through. Lookup probes preserve pre-fill tags; the table shows current contents. Next cache stage stops at each lookup, RAM return, refill, or write-through. Individual bus beats are not modeled.
Click a register for its bits, an ALU unit for its internals, or a cache for its last lookup and stored lines. Continue stops at the next selected event. Breakpoints stop before instruction fetch. Back restores the preceding instruction boundary, including cache probes and output, for up to 128 instructions. Change history retains 128 events.
Inside the selected clock shows actual inputs, logic work, and values latched at its edge. The three display steps do not run the CPU or model electrical propagation delay. During a memory stall, the request remains outstanding and the modeled latency counter advances; RAM internals are not simulated. The compact workspace keeps the machine, explanation, signals, and terminal visible together. Use Code or Fit window to change the layout and Expand to enlarge a detail panel.
The timeline retains up to 4096 cycle samples within 128 instruction checkpoints. Seeking restores and replays the real machine, including cache contents and output. New terminal input in the past starts a new execution branch. Waveforms show state at clock edges, not electrical propagation delays. Value history follows versioned writes; equal numbers are not assumed to share an origin. Address dependencies are shown separately from data dependencies.
Load static ELF32 executables compiled for rv32im / ilp32 using the supplied linker script and runtime. A guest OS, disk, source-level stepping, floating point, and overlapping pipeline execution are not implemented.
